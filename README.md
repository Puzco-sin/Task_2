# Stellar Burgers API tests

Автотесты проверяют только ручки, указанные в задании:

- регистрация и вход пользователя;
- изменение данных пользователя с авторизацией и без неё;
- создание заказа с авторизацией и без неё, с ингредиентами и без них, а также с неверным хешем ингредиента;
- получение заказов авторизованного и неавторизованного пользователя.

## Запуск

```bash
python -m pip install -r requirements.txt
python -m pytest -v
```

По умолчанию тесты обращаются к `https://qa-stellarburgers.education-services.ru`.
Чтобы указать другой адрес API, задайте переменную окружения `STELLAR_API_URL`.

Тесты создают уникальных пользователей и заказы на тестовом сервисе. У API нет
ручки удаления пользователя или заказа, поэтому созданные данные не удаляются.
